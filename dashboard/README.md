# Dashboard

This module will contain the monitoring and visualization interface for VISIONFORGE.

## Planned Features

- PASS/FAIL count
- Total products inspected
- Defect count
- Defect type statistics
- Inspection history
- System status
- Conveyor status
- Rejection statistics

## Future Technology

A web-based dashboard may be developed using:

- Python
- FastAPI
- React
- JavaScript

The dashboard is an optional extension and will be implemented after the core inspection and automation system is functional.
