# Embedded Control

This module contains the ESP32/Arduino firmware for controlling the conveyor, motor and rejection mechanism.

## Responsibilities

- ESP32/Arduino programming
- DC motor control
- Conveyor start/stop
- Motor driver control
- Servo-based rejection
- PASS/FAIL command handling
- LEDs and buzzer
- Actuator timing
- Communication with the computer vision system

## Hardware

- ESP32 / Arduino
- DC geared motor
- Motor driver
- Servo motor
- LEDs
- Buzzer
