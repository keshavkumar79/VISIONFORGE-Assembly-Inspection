# Contributing to VISIONFORGE

## Team Workflow

VISIONFORGE is developed as a collaborative engineering project.

Each team member will work on their assigned module and contribute through GitHub.

## Branch Strategy

The `main` branch contains stable project code.

Individual development should be performed using feature branches.

```text

│

├── feature/rohit-mechanical
